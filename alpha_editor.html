Sky Puf Level Editor

!! 

Controls:
Arrows/WASD to move, [r] to respawn, [z] to clear map;

While in drawing mode, click to add a tile. Drawing modes:
1 for sky, 2 for tile, 3 for wall, [p] for player spawn, [c] for clear player spawn;

"Import Level" loads a level string from the input
"Export Level" saves the current map to a string in input
"Cache Level" adds the level string in input to the cached levels list
THE CACHED LEVEL LIST DOES NOT PERSIST WHEN RELOADING THE PAGE
