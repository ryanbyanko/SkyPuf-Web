# SkyPuf Web

You will lead your Puflings through a maze of floating sky paths. 
Combine Puflings to create new ones and advance through tougher stages -- but watch your step! 
A single slip can send a Pufling over the edge...

**SkyPuf**, the award-winning puzzle game from Vangergame Studios & Ko is now available on the web!
Select any of the six original levels to play, or build your own with the integrated level editor!

## WORK IN PROGRESS

Currently you can load and play the six original levels. The level editor is only somewhat usable (if you use the console).

More editor features and improved graphics to come!
